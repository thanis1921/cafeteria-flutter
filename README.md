# ☕ Aplicación de Cafetería

## Descripción del proyecto
Aplicación móvil desarrollada con Flutter para una cafetería, diseñada para facilitar la consulta de productos y la gestión de pedidos.

## Objetivo general
Desarrollar una aplicación móvil que permita mejorar la experiencia de los clientes y optimizar los procesos de una cafetería.

## Tecnologías utilizadas
- Flutter
- Dart
- GitHub

## Funcionalidades
- Visualización de productos.
- Consulta del menú.
- Interfaz de usuario.
- Gestión de pedidos.

## Estructura del proyecto
- lib/: Código fuente.
- assets/: Recursos e imágenes.
- android/: Configuración para Android.
- test/: Pruebas.

## Instalación
1. Clonar el repositorio.
2. Ejecutar `flutter pub get`.
3. Ejecutar `flutter run`.
